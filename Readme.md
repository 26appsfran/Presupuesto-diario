# Presupuesto Diario

Aplicación web/PWA para llevar el control diario del presupuesto y los gastos.

## Funciones

- Configuración del saldo inicial.
- Fecha del próximo cobro.
- Presupuesto diario.
- Registro de gastos.
- Registro de ingresos.
- Historial de movimientos.
- Cierre diario.
- Arrastre del saldo sobrante o excedido al día siguiente.
- Guardado automático de los datos en el dispositivo.
- Compatible con teléfonos y computadoras.

## Tecnología

Aplicación web desarrollada con HTML, CSS y JavaScript.

Los datos se almacenan localmente en el dispositivo mediante `localStorage`.

## Uso

La aplicación puede instalarse en el teléfono desde Safari utilizando:

**Compartir → Agregar a pantalla de inicio**
